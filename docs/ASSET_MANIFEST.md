# Asset Manifest — Human Record

> Machine record: `assets/asset-manifest.json` (generated by
> `scripts/download_assets.py`). This file is the **human** record: license
> verdicts, reviewer, dates, and which logical asset IDs are mapped to which
> imported files.
>
> **Status: NO PACKS IMPORTED.** Nothing under `assets/` ships yet. The game
> renders geometric primitives and plays no audio, which is the specified
> permanent fallback (FR-017.3, FR-016.6).

## 1. Why this file exists

Redistributing third-party assets requires knowing exactly what was taken,
from where, under which license, and who checked. The importer records
provenance and checksums but **never approves a license**; approval is this
document (SEC-004, BR-018).

## 2. Import procedure (M8, human step)

Kenney's pack pages returned HTTP 403 to automated requests during M1 research
(`docs/research/arcade-references.md` §1), so automated download is not
attempted. The procedure is:

1. Open the official page in a browser and download the ZIP by hand.
2. Import it locally:
   ```bash
   python3 scripts/download_assets.py \
     --archive space-shooter-remastered="$HOME/Downloads/kenney_space-shooter-remastered.zip"
   python3 scripts/download_assets.py --check   # verify checksums
   ```
   Optional preview with `--dry-run`; re-import with `--overwrite` only after
   reviewing the diff.
3. Open the imported `License.txt`/`License.md` inside
   `assets/vendor/kenney/<pack>/` and confirm the pack is CC0 1.0.
4. Fill one row in §4 below **before** committing `assets/vendor/**`.
5. Map the IDs you intend to use in §5; leave everything else unmapped.

Never guess or script a ZIP URL. Never import from a mirror that is not the
official page.

## 7. Rollback

Removing a mapped file (or clearing its row in §5) reverts that ID to its
fallback with no code change. Deleting `assets/vendor/**` entirely returns the
game to its M1 rendering with no rebuild required beyond the static deploy.
