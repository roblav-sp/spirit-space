## 2. Quality-gate reality check (defect D-1)

Constitution §5 and `ai-development-guide.md` §7 require `go vet ./...` and
`go test ./...` to pass. Measured on a clean HEAD:

| Command | Exit | Result |
|---|---|---|
| `gofmt -l .` | 0 | empty (clean) |
| `go vet ./...` | **1** | `imports syscall/js: build constraints exclude all Go files in /usr/local/go/src/syscall/js` |
| `go test ./...` | **1** | same error, from package `spirit-space/cmd/game` |
| `go test ./internal/...` | 0 | `ok spirit-space/internal/game` (13 tests) |
| `GOOS=js GOARCH=wasm go vet ./...` | 0 | clean |
| `./build.sh` | 0 | `Built main.wasm (2.3M)` |

`cmd/game` is untagged but imports `syscall/js`, so it is only compilable for
`js/wasm`. The documented gates therefore never passed literally, contrary to
`specs/traceability.md` ("gates pass") and ADR-0004.

**Proposed remediation (no constitution change needed):** give
`cmd/game/main.go` a `//go:build js && wasm` tag and add a tagged stub so
native `go vet ./...` / `go test ./...` compile. Fixing the code to satisfy
the law is preferred over weakening §5. Tracked as `TASK-INFRA-01` in
`tasks/infrastructure.md`. **Not done in M1** (no code edits this milestone).

> Consequence for this milestone: every gate claim below states the exact
> command variant used. No `go test ./...` claim is made.

## 5. Structural gaps relevant to v0.2

1. **No `LICENSE`/credits file.** Required before redistributing third-party
   assets, even CC0. Owner decision D-5.
2. **No CI.** Gates are manual; ADR-deployment already flags it.
3. **`docs/gameplay.md` is superseded but still present** and still referenced
   from `README.md` as a gameplay pointer. Must not be treated as a spec.
4. **`README.md` says "no dependencies"** — still true for runtime; will need
   a sentence about local assets in M8.
5. **Renderer draws text without setting `font`**; menu work (M2) needs a text
   baseline contract or the HUD will be browser-default sized.
6. **`draw()` never clears input on `blur`** — stuck keys on focus loss
   (already in scope for FR-006/FR-009 in v0.2).
7. **`main.wasm` build is 2.3 MB**; sprites/audio must stay local and budgeted
   (NFR-006).
8. **No test helper for deterministic step-runs** beyond `advance()`, which
   uses float accumulation (`t += step`); a fixed-step harness is needed in M3.
