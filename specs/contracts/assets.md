# Contract — Asset Catalog and Runtime Loading

> **Status: PLANNED (M8).** No asset ships in M1. ADR-0011.

## Two layers

1. **Logical IDs** — stable strings used by Go code and by the manifest.
   Code never contains a file path or a pack name.
2. **Catalog** — `assets/asset-manifest.json`, generated by
   `scripts/download_assets.py` and reviewed by a human. Maps pack files to
   on-disk paths under `assets/vendor/<pack>/…` and records SHA-256.

`cmd/game/assets.go` holds `id → path` after import. Until an import happens the
table is empty and every draw/play call falls back (AC-183).

Adding an ID requires a spec change (this file) and a manifest entry or an
explicit fallback.

## Loading rules

- Loaded once at startup from the page's own origin; no CDN, no data URIs.
- Every load is independent: one failure must not abort the others.
- Failure modes and their fallback are fixed: missing/404 → geometric or silent;
  decode error → same; manifest mismatch → same (plus one warning per ID).
- Decoded sprites keep their aspect ratio (uniform scale to fit `2×radius`);
  no rotation in v0.2.
- Audio buffers are decoded after the first user gesture, not before.

## Budgets

| Bucket | Budget |
|---|---|
| Sprites (PNG/WebP) | 2 MiB |
| Audio (OGG/WAV) | 6 MiB |
| Total runtime payload incl. `main.wasm` | 12 MiB |

`docs/ASSET_MANIFEST.md` records measured totals; AC-186 asserts them.

## Provenance

- `assets/asset-manifest.json` is the machine record: pack, author, license,
  official page, archive source, retrieval time, archive SHA-256, per-file
  SHA-256/size, license files found, `license_review` flag.
- `docs/ASSET_MANIFEST.md` is the human record: review verdict, date, reviewer,
  and which IDs are mapped.
- The importer never self-approves a license; `REVIEW_REQUIRED` and
  `CHECK_LICENSE_CONTENT` both block redistribution until a human signs off.
- Nothing is fetched at runtime (SEC-002, NFR-004).
